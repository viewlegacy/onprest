# API

Every capability the API key may call is available in three ways, all served by the gateway:

| Endpoint | Use it for |
|---|---|
| `POST /api/v1/capabilities/{name}` | Calling a capability from an application. See [REST](/api/rest) |
| `POST /mcp` | Calling capabilities as tools from an AI agent. See [MCP](/api/mcp) |
| `GET /openapi.json` | Generating clients or reviewing the contract. See [OpenAPI](/api/openapi) |

Capabilities that take or return files use the same endpoints plus `GET /api/v1/files/{id}`; see [Files](/api/files). `GET /healthz` reports whether the agent is connected and is the only endpoint that needs no API key; see [Healthz](/api/healthz).

REST and MCP return the same result envelope and the same [error codes](/api/errors).
