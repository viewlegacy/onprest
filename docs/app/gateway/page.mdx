# Gateway

`onprest-gateway` is the public side of Onprest. It authenticates API keys, checks which capabilities each key may call, serves REST, MCP, OpenAPI, and `/healthz`, and accepts the agent's outbound connection. It is configured entirely through environment variables and keeps no state on disk, so restarting it is safe.

- [Configuration](/gateway/configuration): required settings, public URLs, request limits, CORS
- [API Keys](/gateway/api-keys): creating keys and limiting them to capabilities
- [Reverse Proxy](/gateway/reverse-proxy): routes and client IP detection behind a proxy or load balancer
- [Logs](/gateway/logs): the request and control events written to stdout
